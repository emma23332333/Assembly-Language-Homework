# 用 debug -e 直接写内存执行 Hello World

## 操作步骤

### 1. 启动 debug
```
D:\> debug
-
```
出现 `-` 提示符，表示进入调试器。

### 2. 往内存写"数据"（字符串）
字符串 `Hello$` 的 ASCII 码为：`48 65 6C 6F 24`（即 H e l l o $）。

```
-e 076a:2
076A:0002 48. 65. 6C. 6F. 24.
```
含义：在段地址 076A、偏移 2 的位置，依次写入 5 个字节（用空格分隔，回车结束）。

### 3. 往内存写"代码"（机器码）
这段程序对应的 17 字节机器码为：

```
-e 076b:0
076B:0000 b8. 6a. 07. 8e. d8. ba. 02. 00. b4. 09. cd. 21. b8. 00. 4c. cd. 21.
```

### 4. 设置寄存器
```
-r cs
CS 073F :076b        代码段设为 076B
-r ds
DS 073F :076a        数据段设为 076A
-r ip
IP 0100 :0           指令指针设为 0（从第一条指令开始）
```

### 5. 运行
```
-g
Hello

D:\>
```
屏幕输出 `Hello`，程序执行完毕并退出。

## 机器码对照表

| 机器码 | 反汇编指令 | 作用 |
|---|---|---|
| `B8 6A 07` | `MOV AX,076A` | 把数据段地址 076A 送进 AX |
| `8E D8` | `MOV DS,AX` | AX → DS，数据段指向字符串所在位置 |
| `BA 02 00` | `MOV DX,0002` | 字符串偏移地址 0002 送进 DX |
| `B4 09` | `MOV AH,09` | DOS 功能号 9：打印字符串 |
| `CD 21` | `INT 21` | 中断 → 输出 Hello |
| `B8 00 4C` | `MOV AX,4C00` | DOS 功能号 4C00：程序结束 |
| `CD 21` | `INT 21` | 中断 → 退出 |

## 用到的 debug 命令

| 命令 | 作用 |
|---|---|
| `-e 段:偏移` | 修改内存（写入字节） |
| `-r 寄存器名` | 查看/修改寄存器 |
| `-u 段:偏移` | 反汇编（把内存字节翻译回指令） |
| `-g` | 运行程序 |
| `-q` | 退出 debug |
